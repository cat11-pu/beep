# 两段音频拼接验收规范

本规范定义两段音频拼接（含编解码往返）的验收标准。**五项检查全部通过才算验收通过**，
任意一项失败即整体判失败。

## 验收检查项

### 1. 拼接处波形连续（一阶差分检查）

- 计算拼接点两侧样本的一阶差分 `|s[i] - s[i-1]|`（左右声道分别计算，取最大值）。
- 正常范围：两段素材内部所有相邻样本一阶差分的最大值，加容差 `1e-9`。
- 拼接点处的一阶差分超出该正常范围即判失败。
- 实现：`CheckContinuity`（`checks.go`）。

### 2. 拼接点无空白样本

- 拼接点左侧最后一个样本与右侧第一个样本的幅度均不得低于空白阈值 `1e-9`。
- 任一样本为空白（零样本/被丢弃样本）即判失败。
- 实现：`CheckNoBlankAtJunction`（`checks.go`）。

### 3. 总样本数 = 两段之和 − 编码延迟补偿

- 拼接产物总样本数必须等于两段原始样本数之和。
- 显式公式：`总样本数 = 原始拼接长度 − 2 × 编码器延迟`（每段各补偿一次头部延迟，
  尾部 padding 同步裁除）。
- 实测夹具：原始解码流 8256 样本，补偿 2304（2 × 1152）后为 4800，与两段原始长度
  2400 + 2400 一致。
- 实现：`CheckLength`（`checks.go`）。

### 4. 编码器延迟必须补掉，解码后长度与原始一致

- 每段解码后先裁除头部 `EncoderDelay` 个样本，再裁除尾部 `DecoderPadding` 个样本。
- 补偿后的每段长度与样本值必须与编码前原始段逐样本一致（容差 `1e-12`）。
- 拼接产物必须由补偿后的内容构成，不允许残留延迟样本。
- 默认延迟画像采用 MP3 典型值：头部延迟 1152 样本，尾部 padding 576 样本
  （`MP3LikeDelay`）。
- 实现：`CheckDelayCompensation`（`checks.go`），补偿逻辑在 `Splice`/`realContent`
  （`splice.go`）。

### 5. 循环 100 次起点/终点相位不漂

- 对拼接流循环播放 100 次。
- 由信号频率与采样率解析推算每次循环结束处的期望相位，与实际流末尾样本的相位比较。
- 100 次循环内累计相位漂移不得超过 `1e-6`（弧度对应幅值差）。
- 夹具使用 480 Hz / 48 kHz（每周期整 100 样本，段边界为整周期对齐），因此正确实现的
  循环边界天然无缝；任何每循环一次的亚样本偏移都会累积并被检出。
- 实现：`CheckLoopPhaseDrift`（`checks.go`）。

## 证据要求

必须提供拼接前后波形对比图，并标出拼接点：

- 上面板：未做延迟补偿的原始解码拼接流（红色），可见拼接点附近的编码延迟静音区；
- 中面板：延迟补偿后的拼接产物（蓝色），波形连续；
- 下面板：拼接点两侧各 60 样本的局部放大，黄色虚线标注拼接点。

证据图为 SVG 格式（纯标准库生成，无外部绘图依赖），运行验收工具时输出到
`artifacts/splice-evidence.svg`，同时提供转换后的 PNG 便于直接查看。

## 运行方式

```bash
# 运行五项检查的单元测试（含反面用例：未补偿/跳变/空白/相位漂移均必须被拦下）
go test ./acceptance/splice/ -v

# 生成验收报告与波形对比证据图
go run ./acceptance/splice/cmd/splice-acceptance -out artifacts/splice-evidence.svg

# SVG 转 PNG（可选，需要 librsvg）
rsvg-convert -w 1200 artifacts/splice-evidence.svg -o artifacts/splice-evidence.png
```

命令行工具在任一检查失败时以非零状态码退出，适合接入 CI 门禁。

## 判定规则

| 检查 | 通过条件 | 失败含义 |
| --- | --- | --- |
| continuity | 拼接点一阶差分 ≤ 内部最大差分 + 1e-9 | 拼接处有突变/爆音 |
| no-blank-junction | 拼接点两侧样本幅度 ≥ 1e-9 | 拼接点存在空白/丢样本 |
| length | 总样本数 = 两段原始长度之和 | 延迟未补偿或样本丢失 |
| delay-compensation | 补偿后逐样本等于原始段 | 编码器延迟残留 |
| loop-phase-100 | 100 次循环累计漂移 ≤ 1e-6 | 循环边界相位漂移 |

**五项全过 = 通过；任一失败 = 不通过。**
